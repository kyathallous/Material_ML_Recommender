The three citations are already written in data/raw/sources.csv. A file is labelled Experimental (published) only if it is listed there. None of these files contains Young's modulus, density or hardness. To add them, type a cited handbook table into data/templates/reference_table_template.csv, save it in data/raw and list it in sources.csv with kind = reference. It is then labelled Reference data, never "experimental". A file with kind = secondary is also used, but is always labelled Secondary data.
